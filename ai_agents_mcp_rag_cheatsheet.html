🧠 Core LLM Concepts

The fundamentals — assume the interviewer knows these and uses them as shorthand.

Token
Unit LLMs consume/bill on. ~4 chars or 0.75 words in English.
Context Window
Max tokens (input + output) the model can handle in one call.
Input vs Output Tokens
Billed at different rates. Output is usually 3–5x more expensive.
Prompt / Completion
Input you send / output the model returns.
System Prompt
Persistent instructions setting model behavior/role.
Streaming (SSE)
Receiving tokens as generated via Server-Sent Events. Lower TTFT.
TTFT
Time To First Token. Latency to start streaming.
TPS
Tokens Per Second. Throughput while streaming.
Temperature
Randomness control. 0 = deterministic, 1 = creative.
Top-p / Top-k
Sampling strategies that constrain token selection.
Hallucination
Plausible but false generated content. The #1 production problem.
Fine-tuning
Continued training on domain data to adapt a base model.
LoRA / QLoRA
Parameter-efficient fine-tuning — cheap, fast adaptation.
Prompt Engineering
Crafting prompts to get reliable outputs without fine-tuning.
Few-shot / Zero-shot
Few examples in prompt vs. none. Affects accuracy.
Chain of Thought (CoT)
Prompting the model to reason step-by-step.

📚 RAG — Retrieval-Augmented Generation

The pattern for grounding LLMs in your own data. Know both ingestion and query flow.

RAG
Pattern: retrieve relevant docs → augment prompt → generate answer.
Embedding
Vector representation of text. Captures semantic meaning.
Embedding Model
e.g., text-embedding-3, Cohere Embed v3. Outputs the vector.
Dense vs Sparse
Dense = neural embeddings (semantic). Sparse = BM25 (keyword).
Vector Store / DB
Pinecone, Weaviate, Azure AI Search, pgvector. Stores embeddings + text.
ANN Search
Approximate Nearest Neighbor. Fast similarity search at scale.
HNSW
Hierarchical Navigable Small World — common ANN index algorithm.
Cosine Similarity
Distance metric for embeddings. Most common.
Top-k Retrieval
Returning k most similar chunks. Typical k = 3–10.
Chunking
Splitting docs into pieces. Typical: 512 tokens with 20% overlap.
Chunk Overlap
Shared content between adjacent chunks to preserve context.
Hybrid Retrieval
BM25 + vector search combined. Best for production.
Reranker / Cross-Encoder
Second pass that reorders top-k for relevance. Expensive but improves quality.
Query Rewriting
Reformulate user query for better retrieval (expand, decompose).
Grounding
Anchoring generation in retrieved facts. Reduces hallucination.
Citation / Attribution
Linking generated text back to source chunks.
Semantic Cache
Cache responses by embedding similarity, not exact match.
Prompt Caching
Provider-side cache of repeated prefixes. Huge cost savings.

🔌 MCP — Model Context Protocol

Anthropic's open protocol for connecting LLMs to tools/data. Microsoft has adopted it.

MCP Server
Backend that exposes tools/resources via standardized protocol.
MCP Client
The agent/LLM app that connects to MCP servers.
Tool
A function the server exposes. e.g., read_file, send_email.
Tool Schema
JSON schema defining tool inputs AND outputs. LLM uses this to call correctly.
Resource
Data the server manages (docs, files, DB records).
Server Discovery
How agents find and connect to available MCP servers.
Tool Discovery
How agent learns what tools each connected server offers.
Transport
How client/server communicate. Usually stdio or HTTP/SSE.

🔧 Plain API Integration

You hardcode each tool's auth, error handling, schema. LLM needs custom prompts per tool. Doesn't scale to many tools.

⚡ MCP

Standardized protocol. LLM autonomously discovers tools + schemas. One client works with many servers. Built for agent ecosystems.

🎯 Agent Loop & Orchestration

How agents actually work. The mechanics behind "the LLM does it."

Agent Loop
Cycle: observe → think → act → observe. Until done or max steps.
ReAct
Reasoning + Acting. Foundational pattern: thought → action → observation.
Orchestrator
Component managing the agent's execution cycle, retries, termination.
Planner-Executor
Pattern: one LLM plans steps, another executes them.
Multi-Agent System
Multiple specialized agents collaborating on a task.
Tool Call / Function Calling
LLM emits structured request to invoke an external function.
Structured Output
Forcing LLM to return validated JSON matching a schema.
Step / Turn / Iteration
One cycle of the agent loop.
Max-Step Limit
Guard against infinite loops. Hard cap on iterations.
Termination Condition
When agent stops: goal met, max steps, error, user cancel.
Short-term Memory
Current session/conversation context. Lives in Redis or in-memory.
Long-term Memory
Persisted across sessions. Usually via vector store.
Trajectory
Full sequence of an agent's steps for one task.
Tool Gateway
Safe execution layer between LLM intent and real-world action.
Graph-based Planning
State machine/graph for complex non-linear flows (LangGraph style).

⚙️ Concurrency, Rate Limiting & Retries

For the "batch async LLM calls" type questions. These signal production maturity.

Semaphore
Caps concurrent in-flight requests. The mechanism for bounded concurrency.
Bounded Concurrency
Concept of limiting parallel calls. Semaphore is how you implement it.
Fan-out / Fan-in
Launch many parallel calls / collect their results.
Backpressure
Slowing down upstream when downstream can't keep up.
Token Bucket
Rate-limit algorithm. Refills steadily, allows controlled bursts.
RPM / TPM
Requests/Tokens Per Minute. LLM providers limit both. TPM usually binds first.
Quota
Aggregate usage limit (vs. rate limit = instantaneous).
Exponential Backoff
Retry waits: 1s, 2s, 4s, 8s. Doubles each time.
Jitter
Randomization in backoff. Prevents thundering herd. "Full jitter" is the named pattern.
Thundering Herd
Many clients retrying simultaneously. Backoff + jitter prevents it.
Retry Budget
Cap on total retries to prevent retry storms making things worse.
Circuit Breaker
After N failures, stop calling for cooldown. States: closed/open/half-open.
Idempotency
Same request retried = same result. Required for safe retries.
Idempotency Key
Unique ID per logical request. Server deduplicates retries.
Transient vs Permanent
Retry transient (429, 5xx, timeout). Don't retry permanent (400, 401).
Retry-After Header
Server tells you exactly how long to wait. Always respect it.
Dead Letter Queue
Where permanently failed items go for inspection.
Bulkhead Pattern
Isolate resources so one slow tenant doesn't starve others.

🛡️ Safety, Guardrails & Cost

Senior-level concerns. Showing you think about these = production maturity signal.

Guardrails
Safety constraints. STRUCTURAL — enforced by code, not prompts.
Policy Engine
Component deciding what actions are allowed. Sits between LLM and tools.
Human-in-the-Loop (HITL)
Approval gate for irreversible/risky actions.
Sandboxing
Running risky tools in isolated envs (Docker, Firecracker microVMs).
Blast Radius
How much damage a misbehaving action can cause. Minimize it.
Prompt Injection
Malicious input that hijacks the LLM's instructions.
Action Classification
Read = auto-allow. Write = need confirmation. Delete = always HITL.
Token Budget
Per-request/user cap on token spend. Prevents runaway cost.
Model Routing / Cascading
Simple queries → small model. Hard → large model. Saves cost.
Cost per Request / Task
The metric that matters at scale.
Schema Validation
Validate LLM-emitted tool args against schema before executing.

📊 Evaluation & Observability

The hardest unsolved problem in agent engineering. Showing you care = strong senior signal.

Eval / Evals
Offline test suites for agent quality.
LLM-as-Judge
Using a model to grade another model's output.
Golden Set
Curated input/expected-output pairs for regression testing.
Groundedness / Faithfulness
Does the answer match the retrieved facts?
Recall@k
Did the right doc appear in top-k retrieved? Key RAG metric.
Precision@k
How many of top-k results are relevant.
Trace / Tracing
OpenTelemetry-style recording of each agent step for debugging.
Replay
Re-run a stored trajectory to debug or test.
A/B Test
Run two prompt/model variants on real traffic to compare quality.
Drift
Quality degrading over time as inputs/models change.
Regression Test
Ensure new prompt/model version doesn't break old behavior.

💬 Power Phrases — Drop These in Interviews

Sentences that signal "I've built this in production." Use them naturally.

"Guardrails should be structural, not prompted" — the LLM doesn't enforce anything; the policy engine does.
"The LLM is maybe 20% of a production agent system" — the rest is orchestration, tools, memory, observability.
"TPM is usually the binding constraint, not RPM" — shows you've actually hit LLM rate limits.
"Full jitter on exponential backoff to prevent thundering herd" — names a specific AWS-blog pattern, not just "backoff."
"Idempotency keys make retries on partial batch failures safe" — connects two concepts correctly.
"Hybrid retrieval — BM25 plus vector, then rerank with a cross-encoder" — the production RAG pattern.
"Chunking strategy directly determines retrieval quality" — shows you've debugged RAG.
"Embeddings are model-specific — swapping models means re-embedding the corpus" — operational awareness.
"Cost-aware model routing — small models for simple queries, large for hard ones" — production economics.
"Eval is the hardest unsolved problem in agent engineering" — honest take that resonates with senior engineers.
"Action classification — reads auto-allowed, writes need HITL" — concrete safety design.
"Tool gateway sits between the LLM's intent and real-world execution" — clean separation of concerns.
"Trajectories are how you debug agents — like distributed traces for reasoning" — connects to known SRE concepts.
"MCP standardizes what custom tool integrations used to require per-tool" — shows you get the protocol's value.

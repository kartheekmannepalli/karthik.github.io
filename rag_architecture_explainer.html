🟣 The life of an embedding

"Reset your password via…"text chunk
→
Embedding Modelcreates it
→
[0.12, −0.98, 0.33]vector
→
Vector DBstores & compares it

Embeddings are never translated back to text. The Vector DB compares vectors mathematically (cosine similarity), then returns the original text chunks it stored alongside them. The LLM only ever sees text — never vectors.

⚠️ Index and query must use the same embedding model — vectors from different models don't live in the same space and can't be compared.
